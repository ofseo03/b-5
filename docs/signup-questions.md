# 가입 질문 초안 (v0.1)

> 상태: **Claude 초안 → 팀 검토 필요.** [페르소나 형식](persona-format.md) v0.1의 필드를 채우도록 설계했다.
> 목표 시간 5~10분. 질문 12개(필수 10 + 선택 2), 질문당 30~45초 기준 약 6~9분.

## 1. 진행 방식

- **반구조화** — 각 질문은 선택지(빠르게 답하기용)와 자유 입력(페르소나 재료)을 함께 둔다. 선택지만 고르고 넘어가도 되지만, 자유 입력이 비면 꼬리 질문이 나간다.
- **꼬리 질문** — 아래 조건 중 하나면 꼬리 질문을 던진다. **질문당 최대 2개.**
  - 자유 입력이 10자 미만
  - 전처리에서 명사가 하나도 안 나옴
  - 모호한 표현만 있음: `그냥`, `딱히`, `아무거나`, `다 좋아요`, `잘 모르겠어요`, `글쎄요` 등
  - 꼬리 질문은 미리 써 둔 것을 우선 쓰고, 없으면 LLM이 원 질문과 답변을 보고 하나 만든다.
- **건너뛰기** — 선택 질문은 건너뛸 수 있다. 필수 질문을 꼬리 질문 2개 후에도 못 채우면 그대로 진행하고 `meta.missing_fields`에 남긴다.
- **개인정보 고지** — 자유 입력 화면마다 "실명, 연락처, 학교·회사 이름은 적지 마세요. 페르소나는 익명으로 대화합니다." 문구를 둔다.

> ❓ 회의록의 "꼬리 질문 최대 2개"를 **질문당**으로 해석했다. 가입 전체에서 2개라는 뜻이었다면 수정 필요.

## 2. 프로필 (페르소나 내용과 별개)

| # | 화면 | 입력 | 채우는 필드 |
|---|---|---|---|
| P1 | 닉네임을 정해 주세요 | 텍스트 (2~10자) | `profile.nickname` |
| P2 | 나를 대신할 캐릭터를 골라 주세요 | 동물 캐릭터 그리드 | `profile.avatar_id` |

- P1 아래 고지: "닉네임에는 실명, 전화번호, SNS 아이디처럼 나를 알아볼 수 있는 정보를 넣지 마세요."
- 서버에서 전화번호·이메일 패턴은 막는다.

## 3. 페르소나 질문

### A. 취미·관심사

**Q1. 요즘 시간 가장 많이 쓰는 취미는 뭐예요?** (필수)
- 선택지(복수): 영화·드라마 / 음악·공연 / 운동 / 여행 / 게임 / 독서 / 요리·맛집 / 전시·사진 / 기타
- 자유 입력: "구체적으로 알려 주세요. 예: SF 영화를 극장에서 혼자 봐요"
- 꼬리 질문: "그 취미에서 제일 좋아하는 게 뭐예요? (장르, 장소, 최근에 한 것 등)" / "얼마나 자주 해요?"
- → `hobbies[]`, `match_keywords`

**Q2. 최근에 새로 빠진 게 있다면요?** (필수)
- 자유 입력: "작은 것도 좋아요. 예: 요즘 보드게임에 빠졌어요"
- 꼬리 질문: "어쩌다 빠지게 됐어요?"
- → `hobbies[]` 또는 `interests`, `match_keywords`

**Q3. 쉬는 날 하루를 마음대로 쓸 수 있다면 어떻게 보내고 싶어요?** (필수)
- 자유 입력
- 꼬리 질문: "그날 누구랑, 어디서 보내고 싶어요?"
- → `interests`, `relationship.date_style`, `personality` 근거

### B. 성격

**Q4. 친한 친구들은 나를 어떤 사람이라고 해요?** (필수)
- 선택지(최대 3): 성격 태그 목록에서 표시 (차분한, 활발한, 호기심많은, 다정한, 솔직한, 유머있는 …)
- 자유 입력: "친구가 실제로 했던 말이 있다면 적어 주세요"
- 꼬리 질문: "그런 말을 듣게 된 일이 있었어요?"
- → `personality.tags`, `personality.summary`

**Q5. 처음 만난 사람과 대화할 때 나는 어떤 편이에요?** (필수)
- 선택지: 먼저 말을 거는 편 / 상대가 말을 걸면 잘 받는 편 / 시간이 좀 필요한 편
- 자유 입력(선택)
- → `personality.tags`, `conversation.pace`

**Q6. 스트레스 받거나 지칠 때는 주로 어떻게 풀어요?** (필수)
- 자유 입력
- 꼬리 질문: "그러고 나면 기분이 어때요?"
- → `personality.summary`, `hobbies[]` 보강

### C. 말투

말투는 설명보다 **직접 쓴 문장**이 정확하므로 예시 메시지를 받는다.

**Q7. 친한 친구에게 주말 약속을 잡는 메시지를 평소처럼 써 주세요.** (필수)
- 자유 입력 (채팅 말풍선 모양 입력창, 최소 15자 권장)
- 꼬리 질문: "친구가 '좋아! 뭐 할까?'라고 답했어요. 이어서 뭐라고 보낼래요?"
- → `speech_style.sample_messages`, `tone_tags`, `message_length`, `habits`

**Q8. 소개팅 앱에서 처음 대화하는 상대가 "오늘 뭐 하셨어요?"라고 물었어요. 어떻게 답할래요?** (필수)
- 자유 입력 (채팅 말풍선 모양)
- → `speech_style.sample_messages`, `speech_style.formality` 근거

**Q9. 처음 대화하는 상대와는 어떤 말투가 편해요? 이모티콘은요?** (필수)
- 선택지 1: 존댓말 / 반말 / 상대에 맞춰서
- 선택지 2: 거의 안 씀 / 가끔 씀 / 자주 씀
- → `speech_style.formality`, `speech_style.emoji_usage`

### D. 대화·관계 성향

**Q10. 어떤 대화를 할 때 시간 가는 줄 몰라요?** (필수)
- 자유 입력: "예: 좋아하는 영화 얘기, 서로 요즘 빠진 것 공유하기"
- 꼬리 질문: "반대로 금방 지루해지는 대화는요?"
- → `conversation.likes`

**Q11. 처음 알아가는 사이에서는 피하고 싶은 주제가 있어요?** (선택)
- 선택지(복수): 정치 / 종교 / 연애 경험 / 직장·학교 / 외모 / 없음
- 자유 입력
- → `conversation.avoid` (페르소나도 이 주제는 꺼내지 않음)

**Q12. 마음이 맞는 사람을 만나면 어떤 만남을 해 보고 싶어요?** (선택)
- 선택지(복수): 카페 / 맛집 / 산책 / 전시·공연 / 운동 같이 하기 / 영화 / 기타
- 자유 입력: "관계에서 중요하게 생각하는 것이 있다면 같이 적어 주세요"
- → `relationship.date_style`, `relationship.values`

| 필드 | 주 질문 | 보조 질문 |
|---|---|---|

| `speech_style.*` | Q7, Q8, Q9 | — |
| `hobbies` | Q1 | Q2, Q6 |
| `interests` | Q2 | Q3 |

| `relationship.*` | Q12 | Q3 |

## 5. 답변 전처리 (일치율용 명사 추출)

회의에서 "정규식 등으로 명사만 뽑는다"는 안이 나왔다. 한국어는 조사가 붙어서 정규식만으로는 명사 분리가 어렵기 때문에 단계별로 제안한다.

1. **정규화** — 공백·특수문자 정리, 이모지 제거, 개인정보 패턴(전화번호, 이메일, URL) 제거
2. **명사 추출** — 형태소 분석기 사용 권장 (예: Kiwi, Okt). 정규식만 쓴다면 조사 사전(`을/를/이/가/은/는/에서/으로/…`)으로 어절 끝을 잘라내는 방식
3. **불용어 제거** — `것`, `거`, `때`, `요즘`, `그냥`, `시간`, `사람` 등
4. **동의어 통합** — `영화관`→`극장`, `헬스`→`운동`, `런닝`→`러닝` 같은 사전을 두고 대표어로 바꿈
5. **저장** — 결과를 `match_keywords`에 넣고, 일치율 계산은 일단 키워드 겹침으로 시작. 프로토타입은 겹침 계수(`|A∩B| / min(|A|,|B|)`)에 성격 태그 겹침을 조금 더한다 (`server/src/match.ts`). 유사도(임베딩) 방식은 회의 결정대로 대기.

> 표시 범위(60~100%)는 실제 사용자 분포를 계산해 본 뒤 정한다.
