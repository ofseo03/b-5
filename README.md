# b-5

AI 페르소나와 먼저 대화해 보고 마음에 들면 실제 사람과 이어서 대화하는 소개팅 앱.

## 로컬에서 실행하기

Node.js 22.9 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 서버(4000번)와 웹(5173번)이 같이 뜹니다.

- API 키 없이 바로 돌아갑니다. 기본 LLM은 규칙 기반 **mock**이라 페르소나 생성과 페르소나 답장이 단순합니다.
- 처음 켜면 데모 사용자 8명이 만들어집니다. 데이터는 `server/data/db.json`에 저장되고, `npm run reset-db`로 지웁니다.
- 로그인 대신 첫 화면에서 사용자를 고릅니다. 상단의 "사용자 바꾸기"로 상대방 입장도 볼 수 있습니다.

### 시연 순서 예시

1. "새로 가입하기" → 닉네임·캐릭터 → 질문 12개 (답을 짧게 쓰면 꼬리 질문이 나옵니다)
2. 추천 탭에서 일치율 높은 카드를 오른쪽으로 넘기기 (또는 ♥)
3. 상대 페르소나와 대화 (최대 5번) → "대화하기"
4. "사용자 바꾸기"로 상대를 고르면 🔔 알림과 함께 페르소나 대화 기록이 보이고, 이어서 답할 수 있습니다

### 설정

`server/.env.example`을 `server/.env`로 복사해서 바꿉니다.

| 변수 | 기본값 | 설명 |
|---|---|---|
| `LLM_PROVIDER` | `mock` | `anthropic`이면 Claude API 사용 |
| `ANTHROPIC_API_KEY` | | Claude 사용 시 필요 |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | |
| `DECISION_WINDOW_MINUTES` | `1440` | 선택 보류 시간 (24시간). 시연할 때는 `3`처럼 줄이기 |
| `REMINDER_BEFORE_MINUTES` | `60` | 마감 몇 분 전에 알림을 보낼지 |
| `PERSONA_TURN_LIMIT` | `5` | 페르소나와 대화할 수 있는 횟수 |
| `MAX_PERSONA_ROOMS` | `0` | 동시에 열 수 있는 페르소나 채팅방 수 (0 = 제한 없음) |

Claude를 쓸 때는 거절 응답이 나오면 다른 모델이 이어서 답하도록 서버 측 fallback(`fallbacks: "default"`)을 켜 두었습니다. API 호출이 실패하면 로그를 남기고 mock으로 대신해서 화면이 멈추지 않습니다.

## 구조

```
server/            Express + TypeScript API
  src/persona.ts   페르소나 고정 형식 (zod 스키마, 태그 목록, 개인정보 필터)
  src/questions.ts 가입 질문 Q1~Q12
  src/keywords.ts  답변 → 명사 추출 (일치율용), 꼬리 질문 조건
  src/match.ts     일치율 계산
  src/rooms.ts     채팅방 권한, 선택 마감·알림 처리
  src/llm/         mock / anthropic 구현 (같은 인터페이스)
  src/seed.ts      데모 사용자
web/               React + Vite
  src/pages/       가입, 추천(스와이프), 채팅 목록, 채팅방, 내 페르소나
```

## 회의 결정 반영 현황

| 결정 | 구현 |
|---|---|
| 페르소나 채팅방을 실제 대화로 그대로 이어 쓴다 | ✅ "대화하기" 후 같은 방에서 대화, 상대도 페르소나 대화 기록을 봄 |
| "대화하기" 버튼은 항상 켜 둔다 | ✅ 5번을 채우지 않아도 누를 수 있음 |
| 24시간 보류, 1시간 전 알림, 미선택 시 자동 "선택 안 함" | ✅ 시간은 설정으로 조정 |
| 페르소나 대화는 상대에게 알림이 가지 않는다 | ✅ 상대는 "대화하기" 전까지 방을 볼 수 없음 |
| 반구조화 질문 + 고정 형식 | ✅ [가입 질문](docs/signup-questions.md), [페르소나 형식](docs/persona-format.md) |
| 프로필 사진은 동물 캐릭터, 자유롭게 변경 | ✅ 내 페르소나 탭에서 변경 |
| 레벨 기능 없음, 부가 기능 제외 | ✅ |

### 회의에서 정하지 않아 임의로 정한 것

- **선택 마감 기준 시점**: 채팅방이 만들어진 때(오른쪽으로 넘긴 때)부터 24시간
- **상대의 수락 단계**: 회의 결론대로 수락 화면 없이 바로 같은 방에서 이어서 대화. 상대는 알림으로 알게 됨
- **일치율**: 키워드 겹침 계수(`겹친 수 / 둘 중 적은 키워드 수`)에 성격 태그 겹침을 조금 더함. 60~100% 같은 표시 범위 조정은 하지 않고 원값을 보여 줌
- **꼬리 질문**: 질문당 최대 2개
- **채팅방 개수 제한**: 기본은 제한 없음 (`MAX_PERSONA_ROOMS`로 5 또는 10 시험 가능)

### 아직 없는 것

로그인·인증, 실제 DB, 고스팅 지표·신고, 대화 후 피드백, 페르소나 업데이트, 닉네임 변경, 페르소나 말투 추가 학습.
